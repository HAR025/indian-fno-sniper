# Fast Scalper Pro Indicator Suite

A custom, high-conviction scalping indicator system built for personal stock market intraday trading on **MetaTrader 5** and **MetaTrader 4**.

## Highlights

- **Non-Repainting Guarantee:** Signals calculate on bar close; once an arrow appears, it never moves or vanishes.
- **Confluence Architecture:**
  - 9 EMA & 21 EMA directional momentum ribbon
  - 50 EMA major baseline trend filter
  - 14 RSI momentum velocity filter
  - Candlestick price-action rejection & engulfing confirmation
  - Dynamic ATR Take-Profit (TP1, TP2) and Stop-Loss (SL) levels
- **On-Chart HUD Dashboard:** Displays live Trend Bias, RSI Momentum, Volatility (ATR), and active trade parameters.
- **Audio, Screen & Mobile Notifications:** Instant alerts on MT4/MT5 desktop terminal and phone apps.
- **Interactive Simulator (`chart_preview.html`):** Test and observe live ups & downs, signals, and dashboard right in your browser.

## Quick Start

1. Preview the chart simulator: Open `chart_preview.html` in any web browser.
2. Read the setup guide: Open `INSTALLATION_GUIDE.md` for step-by-step MT4/MT5 installation instructions.
3. Install the indicator into MetaTrader (`FastScalperPro.mq5` for MT5, or `FastScalperPro.mq4` for MT4).
